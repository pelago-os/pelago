# Pelago OS icon

A wave rolls across a P: the top of the letter stays above the water, the rest
sinks below it, and a small arc rises over the sea. White monoline on a deep blue
gradient. `pelago-icon.svg` is the source; `frontend/icon-192.png`,
`icon-512.png`, `apple-touch-icon.png` (square, iOS rounds it) and
`frontend/favicon.svg` are exported from it.
