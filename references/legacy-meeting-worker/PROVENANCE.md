# Provenance and contribution status

Prepared by the project maintainers / Pelago OS Authors from a historical worker snapshot, source revision `19a17c46d664f9368c915f18889fe45ea4e4f76e`. Original private Git history is not included or merged. Source bundles are preserved privately by maintainers; their private storage paths and personal contributor identities are not part of this export.

The later incremental bundle was applied only after verifying that its prerequisite commit exists in the reconstruction repository. This export selects eight files, not the whole original tree. Private reviews, service templates, original tests, Git metadata and runtime artifacts were excluded. Python warning comments were added. Personal routes and site branding were replaced with fictional identifiers, workstation labels and an example protocol header. These header/config changes mean this is NOT a byte-identical or wire-compatible historical distribution. Core logic, including known unsafe historical behavior, was not productized.
